# md2excel（Markdown → Excel .xlsx 変換）

Markdown ファイル（UTF-8）を読み取り、Apache POI を使って Excel（.xlsx）に整形出力するツールです。
仕様書・設計書の Markdown を、**見出し / 段落 / リスト / 引用 / 表 / コードブロック** などの体裁をできるだけ保ったまま Excel に落とし込みたい用途を想定しています。

本リポジトリは個人による開発であり、特定の組織・雇用主とは無関係です。

* 入力: Markdown（UTF-8）
* 出力: Excel（.xlsx）
* シート名: `spec`

---

## 主な機能

### ブロック要素

* 見出し

  * ATX 形式 `#` / `##` / `###` / `####` 以降に対応
  * `#` / `##` / `###` はそれぞれサイズ違いの太字スタイル
  * `####` 以降は通常サイズの太字扱い
  * 行末の閉じ `#` を許容（例: `## title ##`）
  * Setext 形式にも対応

    * `=` による level 1
    * `-` による level 2
  * 見出し内の太字 / 斜体 / インラインコードをリッチテキストで反映
  * トップレベル見出しは **B 列起点**

* 通常段落（テキスト）

  * トップレベルは **B 列起点**
  * インデント量に応じて列を右へ
  * 複数の入力行を段落単位で集約して解析
  * soft break は段落内の空白として扱う
  * `<br>`、行末 2 スペース、行末 `\` による hard break に対応
  * 行をまたぐ太字 / 斜体などの inline 書式を保持

* 箇条書き `* ` / `- ` / `+ `

  * 先頭に `・ ` を付与して出力
  * トップレベルは **C 列起点**
  * ネスト（インデント）に応じて列が右へ
  * hard break を含む場合は縦展開し、継続行は 1 列右へ出力

* 番号付きリスト `1. ` / `1) ` / `12. ` / `12) `

  * トップレベルは **C 列起点**
  * ネスト（インデント）に応じて列が右へ
  * hard break を含む場合は縦展開し、継続行は 1 列右へ出力

* リスト共通

  * リスト項目直下の**字下げした説明行**は、状態に応じて**直前のリスト項目セルへ追記**される場合あり
  * 親リスト配下の**ネストした子リスト（およびその説明行）**が終わり、**浅い階層のリストへ戻る場合**、見やすさのため**自動空行を 1 行**挿入
  * このルールは **引用ブロック外 / 引用ブロック内の両方** に適用
  * 対象例:

    * `- a` → `  - b` → `- c`
    * `1. a` → `   1. b` → `2. c`
    * `- a` → `  1. b` → `- c`
    * `1. a` → `   - b` → `2. c`
    * `- a` → `  - b` → `  c` → `- d`
    * `> - a` → `>   - b` → `>   c` → `> - d`

* 引用 `>`

  * `>` の後ろに空白がなくても引用として扱う
  * 引用内の内容を通常ブロックと同じ構文判定に通して解析
  * **引用テキストは通常本文より 1 列右**に配置

    * 例: トップレベル本文が B 列なら、トップレベル引用本文は C 列
  * 左端には **太い青線**、背景はコードブロックと同系色で塗る
  * 引用の装飾（左罫線・塗りつぶし）は、引用本文の **1 列左から**適用
  * 引用内で以下の block element を描画可能

    * 見出し
    * 水平線
    * 箇条書き
    * 番号付きリスト
    * テーブル
    * fenced code block
    * ネストした引用
  * 引用内の見出しは、見出しのフォント・サイズを維持しつつ引用背景を適用
  * 引用内の水平線は、引用罫線列の 1 列右から描画
  * 引用内のテーブルはテーブル罫線を維持しつつ引用背景を適用
  * 引用内の fenced code block は、コードブロックの枠・背景・等幅フォントを維持
  * ネストした引用は深さに応じて左青色罫線と本文列を右へ追加

    * 1 段目: B 列に引用罫線、C 列に本文
    * 2 段目: B / C 列に引用罫線、D 列に本文
  * 引用内の**字下げした説明行**は、状態に応じて**直前の引用内リスト項目セルへ追記**される場合あり
  * 引用内の**ネストした子リスト（およびその説明行）**が終わり、浅い階層のリストへ戻る場合は、**引用内の空行**を自動挿入
  * 引用内空行も可視の空行として出力

* コードブロック（フェンス ``` / `~~~`）

  * 背景グレー、外周に枠線
  * コード本文は **ブロック開始位置の 1 列右** に配置

    * 例: トップレベルでは **C 列**
  * コードブロックの装飾（塗りつぶし・外周枠線）は、コード本文の **1 列左から**適用

    * 例: トップレベルでは **B 列から**
  * **見出し直後**にコードブロックが続く場合は、**コードブロック開始前に 1 行の自動空行**を挿入
  * コードブロック前の Markdown 空行は保持する
  * フォントは英数字を `Consolas`、日本語を `Meiryo` に切替
  * 開始フェンス後ろの info string を許容
  * 閉じフェンスは「開始時と同じ記号」「開始以上の長さ」「後続は空白のみ」で判定
  * 引用ブロック内の fenced code block にも対応
  * コードブロック内では emphasis / list / table などの Markdown 解釈を行わない

* 水平線

  * `---` に加え、`***` / `___` / `- - -` / `* * *` などにも対応
  * 空白・タブを含んでいても、同一記号（`-` / `*` / `_`）が 3 個以上であれば水平線として扱う
  * 行全体に下線（hairline）を描画
  * 水平線行は空行用スタイル（6pt）ベース
  * 引用ブロック内の水平線にも対応
  * Setext 見出しとして成立する `---` は水平線ではなく level 2 見出しとして処理

* テーブル（パイプ `|` 形式）

  * `| a | b |` のような行に加え、`a | b` のように先頭 / 末尾の `|` がない行もテーブル行として扱う
  * 区切り行 `|---|---|`（`:` も可、空白可）をヘッダ区切りとして扱う
  * **未エスケープの `|` をセル区切りとして処理**
  * GFM の挙動に合わせ、インラインコード内であっても未エスケープの `|` はセル区切りとして扱う
  * セル内で literal `|` を表現する場合は `\|` を使用
  * セル内の `\|` は `|` に復元
  * body のセル数が header より多い場合は header 数までで切り詰め
  * body のセル数が header より少ない場合は空セルで補完
  * セル内の `<br>` は複数の Excel 行へ展開
  * 同じ Markdown 行から `<br>` によって展開された Excel 行同士には、途中の下罫線を描画しない
  * セルごとに `<br>` の数が異なる場合は不足分を空セルで補完
  * ヘッダ行は太字＋下線、ボディ行は薄い下線、最終行だけ下線なし
  * 引用ブロック内のテーブルにも対応
  * 引用内テーブルではテーブル罫線を維持したまま、指定終了列まで引用背景を適用

> 注意: 表は `.xlsx` 生成後に、必要に応じて手動で列幅調整などの体裁調整を行ってください（自動の列幅最適化は行いません）。

## インライン要素（セル内の装飾）

* 強調（太字 / 斜体）

  * 太字 `**bold**` / `__bold__`
  * 斜体 `*italic*` / `_italic_`
  * 太字＋斜体の組み合わせに対応
  * 判定は逐次トグルではなく、CommonMark 寄りの **delimiter run 解決**で実装

    * Unicode の whitespace / punctuation を考慮
    * `_` の単語内誤検出抑止あり
    * delimiter run の **rule of 3** を反映
    * `***` / `___` のような複合 run に対応
  * 複数入力行にまたがる emphasis に対応
  * 見出し内の斜体でも、見出し由来の太字属性を維持

* インラインコード（複数長バッククォート対応）

  * 単一の `` `code` `` だけでなく、複数長バッククォート列にも対応
  * コード中にバッククォートを含むケースを考慮
  * 赤字、等幅（ASCII は `Consolas` / CJK は `Meiryo`）
  * インラインコード内の `<br>` は分割しない

* 改行

  * 段落全体を 1 回 inline 解析してから表示行へ展開
  * soft break は空白として処理
  * コード外の `<br>` を hard break として解釈
  * 行末の「半角スペース 2 個以上」または「バックスラッシュ `\`」も hard break として扱う
  * hard break では Excel 上の次行へ縦展開
  * 改行をまたぐ太字 / 斜体などの inline 状態を段落解析によって保持

## 差別化ポイント（md2excel の狙い）

一般的な「Markdown→表だけ」変換ではなく、**設計書の読みやすさ**を優先して Excel に整形します。

* **出力開始位置は B2**
* **空行は 6pt の専用スタイル**で扱い、見やすい余白を作る
* Markdown を単純な 1 行単位ではなく、**段落単位で解析**
* **soft break / hard break / `<br>` と inline 書式を組み合わせても書式を維持**
* **ネストしたリスト終了後に親階層へ戻るとき**は、引用ブロック内外を問わず **自動空行**で見やすさを確保
* **引用 `>`** は container block として扱い、見出し / 水平線 / リスト / 表 / コードブロック / nested quote を描画
* **ネストした引用**は深さに応じて左罫線と本文列を右へ展開
* **引用内リストの説明行**も含めて、継続規則を整理
* **コードブロック**は背景グレー＋外周枠線、ASCII / 日本語でフォントを切替
* **テーブルセル内 `<br>`** は複数 Excel 行として展開
* **インライン装飾**は太字 / 斜体 / インラインコードをセル内リッチテキストで反映
* Setext 見出しやテーブル内 pipe など、CommonMark / GFM の解釈を意識して処理

## 動作環境

* Java 8 以上
* Apache POI（XSSF / `XSSFWorkbook` を使用）
* Swing（`JFileChooser` / `JOptionPane` を使用）

> 注意: 本ツールは処理完了時に `JOptionPane.showMessageDialog(...)` を呼びます。
> サーバー等の headless 環境で実行する場合は、GUI 呼び出し部分を無効化するなどの調整が必要です。

## 使い方

本ツールは **GUI（ダイアログ）で設定**します。
コマンドライン引数による詳細設定は行わず、実行時にダイアログで入力します。

### 実行方法

* IDE から `md2excel.app.MarkdownToExcel` を実行
* またはコマンドラインから main を実行

```text
java ... md2excel.app.MarkdownToExcel
```

### 実行時に表示されるダイアログ

次の順にダイアログが出ます。

1. Markdown ファイル選択（`JFileChooser`）
2. `mergeCols` 入力（既定: 40）
3. フォント選択（既定: 游ゴシック）
4. 縦位置選択（上揃え / 上下中央揃え / 下揃え、既定: 下揃え）
5. `# / ## / ### / 通常` のフォントサイズ入力

   * 既定: `16 / 14 / 12 / 11`

出力ファイルは入力ファイルと同じ場所に `.xlsx` 拡張子で生成されます。

## 変換ルールの概要

### 開始位置

* 出力開始セルは **B2**
* 1 行目は空行用スタイル（6pt）で確保される

### 列配置（ざっくり）

* トップレベル見出し / 通常段落 / 表 / 水平線は **B 列起点**
* トップレベルコードブロック本文は **C 列起点**
* コードブロックの装飾（塗りつぶし・外周枠線）は **B 列起点**
* トップレベル箇条書き / 番号付きは **C 列起点**
* トップレベル引用本文は **C 列起点**
* 引用の装飾（左罫線・塗りつぶし）は **B 列起点**
* 2 段目の引用では **B / C 列に引用罫線、D 列に本文**
* インデントやネストが深くなると右へ展開
* `mergeCols` を超える列は右端に丸め込み（clamp）

### 段落と改行

* 同種の連続行は `ParagraphBuffer` に集約してから inline 解析
* soft break は空白として処理
* `<br>`、行末 2 スペース、行末 `\` は hard break として処理
* hard break により表示行が複数になる場合は Excel 行を縦展開
* inline emphasis は入力行の境界をまたいで保持

### リストの補足

* リスト項目直下の**字下げした説明行**は、状態に応じて**直前のリスト項目セルへ追記**される場合がある
* **ネストした子リスト（およびその説明行）**が終わり、**浅い階層のリストへ戻る場合**は、自動空行を 1 行挿入
* この自動空行は Markdown 由来の空行ではなく、見やすさのためにレンダラが補う空行
* **引用ブロック内でも同じルール**を適用し、その場合は**引用内空行**として出力する

### 引用の補足

* 引用 marker を除去した内容を、通常ブロックと同じ classifier で解析
* nested block quote は再帰的に解析
* 行ごとの引用情報は `RenderState` で管理

  * 行種別
  * 引用深度
  * 本文列
* 引用深度に応じて左罫線と本文位置を決定
* table / code / horizontal rule などは、それぞれ固有のスタイルを維持しながら引用装飾を適用

### `mergeCols` の考え方

* `mergeCols` は **シート左端（A 列）基準の列数**
* 既定値は `40`
* 既定の `mergeCols=40` では:

  * 列幅設定対象: **A〜AN**
  * 実際の描画範囲: **B〜AM**

### シート設定

* グリッド線表示・印刷ともに OFF
* `0..mergeCols-1` の列幅を固定

  * POI 内部幅は `3.125 * 256`
  * Excel 上の見た目は **約 2.5**
* 使用列には既定セルスタイルを設定
* 空行用スタイルは **6pt**
* 通常本文の既定フォントサイズは **11pt**

## 制限事項・非対応（現状）

* 見出しは以下に対応

  * ATX 形式 `#`
  * Setext 形式 `=` / `-`
* 強調は **太字 / 斜体 / インラインコード** に対応
* 打ち消し線 `~~text~~`、リンク、画像などは未対応
* コードブロックは fenced code block（``` / `~~~`）のみ
* インデントコードブロック等は未対応
* テーブルは pipe `|` を利用した GFM 形式を対象
* テーブル内の未エスケープ `|` は、インラインコード内であってもセル区切りとして扱う

  * literal `|` が必要な場合は `\|` を使用
* Markdown の全 CommonMark / GFM 構文を完全実装することを目的とはしていない

## ソース構成（役割メモ）

### パッケージ

* `md2excel.app`（起動）
* `md2excel.config`（設定）
* `md2excel.excel`（Excel / POI ユーティリティ・Style）
* `md2excel.markdown`（Markdown 文字処理・リスト深さ等）
* `md2excel.render`（レンダリング本体）

### 主なクラス

* `md2excel.app.MarkdownToExcel`
  エントリポイント。設定読み込み → Markdown 読み込み（Stream）→ 描画 → xlsx 出力。

* `md2excel.config.Md2ExcelConfig`
  GUI から設定値を作る。

* `md2excel.render.MarkdownRenderer`
  入力行を `LineInfo` として分類し、block boundary の制御と各 block renderer への dispatch を行う。
  引用内容は引用 marker を除去したうえで通常と同じ classifier へ通し、nested quote は再帰的に解析する。

* `md2excel.render.ParagraphBuffer` / `md2excel.render.ParagraphUtil`
  通常文・引用・箇条書き・番号付きリストなどの複数入力行を段落単位で集約し、soft break / hard break を含めて inline 解析・描画する。

* `md2excel.render.RenderState` / `md2excel.render.RenderContext`
  レンダリング状態と共有オブジェクトを保持。
  引用行については行種別・引用深度・本文列などのメタ情報も管理する。

* `md2excel.excel.MdStyle`
  Excel の各種 `CellStyle` を生成（見出し、空行、表、引用、コード枠、引用内見出し・表・水平線など）。

* `md2excel.render.MarkdownInline`
  セル内のリッチテキスト（太字 / 斜体 / インラインコード）と、段落内の soft break / hard break 解決を処理。

* `md2excel.render.MarkdownTable`
  テーブル行の解析とセル生成、GFM pipe の区切り、セル内 `<br>` の複数 Excel 行への展開、罫線処理を担当。

* `md2excel.render.MdBlockBoundary`
  見出し・テーブル・引用・リストなどの block 境界における状態遷移や自動空行を制御。

* `md2excel.render.BlockQuoteUtil`
  `RenderState` に記録された引用行メタ情報をもとに、引用の左罫線・背景・nested quote の深さ別装飾を適用する。

* `md2excel.render.RowUtil` / `md2excel.render.CellAppendUtil`
  Excel 行の生成・再利用、セルへの追記を担当。

* `md2excel.markdown.ListStackUtil` / `md2excel.markdown.MdTextUtil`
  リスト深さ管理、Markdown 文字処理ユーティリティ。

* `md2excel.excel.Md2ExcelSheetUtil`
  水平線行などのシート出力ユーティリティ。

## 生成結果の例（概念）

入力例:

````markdown
## Title

paragraph
continued line

- item1<br>detail

> ### quoted heading
>
> quote text
>
> > nested quote
>
> ```text
> *not italic*
> ```

| a | b |
|---|---|
| **x**<br>next | `y` |
````

出力イメージ:

* 見出しは **B 列** に見出しスタイルで出力
* 通常段落の連続行は段落として解析
* 箇条書きは **C 列**、hard break の継続行は右側へ展開
* 引用本文は **C 列**、左罫線と背景は **B 列** から適用
* nested quote は引用深度に応じて罫線と本文を右へ展開
* 引用内見出しは見出しスタイルを維持
* 引用内コードブロックはコードとしてそのまま描画
* 表はヘッダ太字、セル内の強調やインラインコードをリッチテキストで反映
* テーブルセル内 `<br>` は複数 Excel 行へ展開
