# md2excel v3.0.1 Release Notes

- リリース日: 2026-09-22
- 前バージョン: v3.0.0

## 概要

v3.0.1 は、v3.0.0 の外部動作を維持したまま、内部実装の整理とテスト強化を行ったメンテナンスリリースです。

主な目的は、今後の変更を安全に行えるように既存動作を characterization test で固定し、影響範囲を限定した小規模なリファクタリングを実施することです。

## 主な変更

### 内部リファクタリング

- 表の文字列解析処理を描画処理から分離
  - 表判定、セル分割、エスケープされた `|` の扱いなどを専用の内部処理へ整理
  - 既存の公開 API と描画結果は維持

- 通常リストの段落開始処理を共通化
  - 箇条書きと番号付きリストの重複処理を局所的に整理
  - 空行判定、リスト階層更新、開始列・継続列、既存書式の挙動を維持

- `RenderState` の内部遷移処理を整理
  - private な `apply` メソッドから未使用の `col` 引数を削除
  - 状態更新ロジックや更新順序は変更なし

- EOF 終了処理の契約を明示
  - 段落、未閉鎖コード枠、表、引用装飾を確定する既存順序をコメントで明文化
  - 実装コードや終了順序そのものは変更なし

## テスト強化

既存動作を安全に維持するため、characterization test を大幅に追加しました。

主な追加対象:

- 段落結合、ハードブレーク、Setext 見出し
- 空行、ブロック境界、EOF 処理
- 表の複数行展開、列数境界、エスケープされたパイプ
- 表文字列解析の境界条件
- 保存後のリッチテキスト・フォント・配置・罫線などの書式
- 箇条書き／番号付きリストのハードブレーク、最小列数、混在ネスト

テスト数は v3.0.0 時点の 145 件から 238 件へ増加しました。

## 互換性

v3.0.1 では、ユーザー向け機能、公開 API、Excel 出力仕様の意図的な変更はありません。

既存の Markdown 解析結果、セル値、配置、書式、保存動作を維持することを前提に内部改善を行っています。

## 備考

今回のリファクタリングでは、変更効果が限定的またはリスクに見合わないと判断した候補については、無理に実施せず保留としました。

今後は、実際の機能追加や不具合修正で変更が必要になった箇所を優先して、必要に応じて追加のリファクタリングを検討します。
