# Release Notes - v2.2.0

## 概要

v2.2.0 では、Markdown から Excel への変換結果について、**レイアウトの見やすさ・空行表現・引用ブロック・リスト処理**を中心に大きく改善しました。

主なテーマは以下です。

- 出力開始位置を **A1 から B2** に変更
- 空行スタイルを導入し、**空行を 6pt** で表現
- 通常本文の既定フォントサイズを **11pt** に変更
- 引用ブロックの配置・継続・装飾を改善
- リスト前後 / 見出し後 / 引用前後の空行ルールを整理
- `mergeCols` と列幅・描画範囲の扱いを見直し

> v2.1.4 からの更新では、生成される Excel の行位置・列位置・余白感が変わるため、  
> 既存の帳票や比較用途では出力差分の確認を推奨します。

---

## 互換性に影響する変更

### 1. 出力開始位置を B2 に変更
これまでの出力は A1 起点でしたが、v2.2.0 では **B2 起点** になりました。

- 見出し / 通常段落 / 表 / コードブロック / 水平線: **B列起点**
- 箇条書き / 番号付きリスト: **C列起点**
- 引用本文: **C列起点**
- 引用の装飾（左罫線・塗りつぶし）: **B列起点**

### 2. 通常本文の既定フォントサイズを 11pt に変更
- 旧: 10pt
- 新: **11pt**

### 3. 空行専用スタイルを導入
空行は **6pt** の専用スタイルで出力されます。

- Markdown 空行
- 自動挿入空行
- 水平線行
- 引用内空行

### 4. 縦位置の既定値を下揃えに変更
縦位置ダイアログの既定値を **下揃え** に変更しました。

---

## 主な改善点

## 1. 引用ブロックの改善

### 引用本文を 1 段インデント
引用ブロック本文は通常本文より 1 列右に出力されます。

例:
- 通常本文: B列
- 引用本文: C列
- 引用内番号付き / 箇条書き: D列
- 引用内継続行: E列

### 引用装飾は本文の 1 列左から適用
引用の左罫線と背景塗りつぶしは、本文セルの 1 列左から適用されます。

例:
- 引用本文が C列
- 装飾は B列から開始

### 引用の左罫線を太線化
引用ブロックの左罫線は **`BorderStyle.THICK`** を使用します。

### 引用内空行を可視化
引用内の空行も Excel 上で見える空行として扱います。  
また、引用内空行にも引用の装飾を維持しつつ、**空行用 6pt スタイル**を適用します。

### 引用継続処理を改善
以下のケースで、意図した引用継続が行われるよう調整しました。

- `> text  ` の次行が通常文の場合
- `> text  ` の次行が引用内リストの場合
- 引用内番号付き / 箇条書き / 継続行が混在する場合

---

## 2. リスト処理の改善

### 見出し直後の箇条書きでも自動空行を挿入
従来は番号付きリストのみ見出し直後に空行が入りやすい状態でしたが、  
v2.2.0 では **箇条書きでも見出し直後に自動空行**が入ります。

### リスト前後の空行ルールを整理
以下のようなケースで、Markdown 上の空行や期待される視覚的余白が保持されるようになりました。

- 通常文 → リスト
- リスト → 通常文
- hard break 後 → リスト
- 引用内通常文 → 引用内リスト

### hard break 後の継続制御を改善
行末 `  ` または `\` による hard break の後で、

- 通常文継続
- 引用継続
- リスト開始

が混ざるケースでも、意図した空行・継続先・列位置になるよう調整しました。

---

## 3. 空行・余白表現の改善

### 空行を 6pt に統一
空行は専用スタイルを使用し、**フォントサイズ 6pt** で出力されます。

対象:
- Markdown 空行
- 自動空行
- 水平線行
- 引用内空行
- 開始位置より前の事前作成行（例: 1行目）

### 水平線行も空行ベースの見た目に調整
水平線行は空行スタイルをベースにしつつ、下線（hairline）を付与する形に調整しました。  
これにより、余白感を維持しながら水平線を表示できます。

### 空行再利用ルールを調整
行の再利用によって期待しない詰まり方や余分な空行が出ないよう、以下の境界条件を見直しました。

- 水平線前後
- 引用開始前
- 引用終了後
- リスト開始前
- リスト終了後
- 見出し直後

---

## 4. 列幅・描画範囲の改善

### `mergeCols` の解釈を整理
`mergeCols` は **シート左端（A列）基準の列数**として扱います。

既定値 `40` の場合:

- 列幅設定対象: **A〜AN**
- 実際の描画範囲: **B〜AM**

### 列幅を固定
列幅は固定値で設定します。

- POI内部幅: `3.125 * 256`
- Excel 表示上の幅: **約 2.5**

> 全列に対する列幅設定は処理負荷が高いため、使用範囲のみ設定する方針を維持しています。

---

## 5. スタイル関連の変更

- 通常本文の既定フォントサイズを **11pt**
- 空行フォントサイズを **6pt**
- 引用内空行用の専用引用スタイルを追加
- 水平線スタイルを空行ベースに変更
- 縦位置の既定値を **下揃え**

---

## 技術的な変更点

- 出力開始位置オフセット（B2 開始）に対応
- `mergeCols` と描画上限列の計算を修正
- 引用内空行を行番号ベースで管理し、閉じ処理時に正しいスタイルを適用
- ブロック境界処理（見出し / リスト / 引用 / 水平線）の責務を整理
- hard break 継続時の pending 状態遷移を改善
- README を現行仕様に合わせて更新

---

## 利用者向け注意事項

v2.2.0 では、生成結果のレイアウトが v2.1.4 から変わります。  
特に以下の点に注意してください。

- 行番号が変わる
- 列位置が変わる
- 空行の見え方が変わる
- 引用ブロックの位置・装飾が変わる
- リスト前後の余白が変わる

既存の期待結果と比較している場合は、Excel の差分確認を推奨します。

## 既定値（v2.2.0）

- 出力開始位置: **B2**
- `mergeCols`: **40**
- 通常本文フォントサイズ: **11pt**
- 空行フォントサイズ: **6pt**
- 縦位置既定値: **下揃え**
- 引用左罫線: **THICK**
- 列幅: Excel 表示上 **約 2.5**
