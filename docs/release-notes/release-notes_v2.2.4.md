# Release Notes - v2.2.4

## 概要

v2.2.4 では、**ネストしたリストの空行挿入ルール**と、**引用ブロック内のネストリストの継続行処理**を中心に修正しました。

主な改善点は次のとおりです。

- 子リスト開始前ではなく、**子リスト終了後に親階層へ戻るタイミング**で自動空行を挿入
- 子リスト配下の**説明行**を考慮した空行挿入に対応
- **引用ブロック内**でも同じルールを適用
- 引用内の字下げした説明行が、**直前のリスト項目セルへ追記**されるよう修正

本リリースは **後方互換性のあるバグ修正リリース**です。

---

## 修正内容

### 1. ネストしたリストの自動空行挿入位置を修正

従来は、親リストから子リストへ入る前に空行が挿入されるケースがありました。  
v2.2.4 では、**ネストした子リストが終わって浅い階層へ戻る直前**に空行を入れるよう修正しました。

対象例:

```md
## test

- a
  - b
- c

1. d
   1. e
2. f

- g
  1. h
- i

1. j
   - k
2. l
```

期待される出力:

- 5 行目: `b`
- 6 行目: 空行
- 10 行目: `e`
- 11 行目: 空行
- 15 行目: `h`
- 16 行目: 空行
- 20 行目: `k`
- 21 行目: 空行

---

### 2. 子リスト直下の説明行を考慮した空行挿入を修正

ネストした子リストの後に字下げした説明行が続く場合、その説明行も子リスト側の内容として扱い、  
**説明行の後で親階層へ戻る際に空行を挿入**するよう修正しました。

対象例:

```md
## test

- a
  - b
  c
- d
```

期待される出力:

- 5 行目: `b c`
- 6 行目: 空行
- 7 行目: `d`

---

### 3. 引用ブロック内でも同じルールを適用

従来は、引用ブロック内のネストリストでは上記ルールが十分に反映されないケースがありました。  
v2.2.4 では、**引用ブロック内でも、ネストした子リスト終了後に浅い階層へ戻る際の自動空行ルール**を適用するよう修正しました。

---

### 4. 引用ブロック内の説明行追記を修正

引用内の字下げした説明行が、直前のリスト項目セルへ追記されず、別行に出力されるケースを修正しました。

対象例:

```md
## test

> - a
>   - b
>   c
> - d
> 
> - e
>   - f  
>   g
> - h
```

期待される出力:

- `c` は `b` と同じセルに追記される
  - 例: セル `E5` に `・ b c`
- `g` の後に**引用内空行**が 1 行入る
- `h` はその次の引用リスト項目として出力される
