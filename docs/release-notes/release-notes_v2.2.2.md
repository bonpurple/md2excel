# Release Notes v2.2.2

## 概要

v2.2.2 では、ネストしたリストの描画に関する不具合を修正しました。  
親リストの直下に子リストが続く場合、意図した位置に1行空けて出力されるよう改善しています。

## 修正内容

### ネストしたリスト開始位置の修正

以下のような Markdown において、子リストの開始行が1行上に詰まってしまう問題を修正しました。

#### 対象パターン
- 番号付きリストの子が箇条書きリストである場合
- 番号付きリストの子が番号付きリストである場合
- 箇条書きリストの子が番号付きリストである場合
- 箇条書きリストの子が箇条書きリストである場合

#### 修正例 1
```md
## test

1. a
   - b
   - c
```

修正後:
- `b` が期待通り1行空いた位置に出力されます

#### 修正例 2
```md
1. a
   1. b
   2. c
```

修正後:
- `1. b` が親項目 `1. a` の直後に詰まらず、1行空いた位置に出力されます

#### 修正例 3
```md
## test

- a
  1. b
  2. c
```

修正後:
- `1. b` が期待通り1行空いた位置に出力されます

## 仕様補足

- 引用ブロック内のネストリスト挙動は変更していません
- 既存の設定項目、入力方法、出力ファイル形式に変更はありません
- 互換性に影響する破壊的変更はありません

## 影響範囲

- Markdown のリスト描画処理
- ネストした箇条書き／番号付きリストの行配置

## 互換性

- 後方互換性あり
- 設定ファイル変更不要
- 利用方法の変更不要

## バージョン

- v2.2.1 → v2.2.2

## 備考

本リリースは不具合修正を目的としたパッチリリースです。
