# Release Notes - v2.2.1

## 概要

v2.2.1 は不具合修正を中心としたパッチリリースです。  
コードブロックの出力位置と、コードブロック前の空行の扱いを修正しました。

- 種別: **Patch release**
- 互換性: **後方互換あり**
- 設定変更: **なし**
- 破壊的変更: **なし**

---

## 修正内容

### 1. コードブロック本文の配置を修正

トップレベルのコードブロック本文が **B 列** に出力されていたケースを修正し、  
本文を **C 列** に出力するよう変更しました。

あわせて、コードブロックの **塗りつぶしと外周罫線は B 列から** 適用されるよう修正しました。

#### 変更前
- コード本文: **B 列**
- コードブロック装飾: **B 列**

#### 変更後
- コード本文: **C 列**
- コードブロック装飾: **B 列**

---

### 2. コードブロック前の Markdown 空行を保持

コードブロック直前の Markdown 空行が、コードブロックの行として再利用されることがあり、  
結果としてコード本文が想定より 1 行上に詰まる場合がありました。

v2.2.1 では、**コードブロック前の Markdown 空行を保持し、再利用しない** よう修正しました。

---

## 具体例

入力:

````md
## test

a

```text
b
```
````

### v2.2.0
- `b` が **B5** に出力される場合がある

### v2.2.1
- `b` が **C6** に出力される
- コードブロックの背景色・外周罫線は **B 列から** 適用される

---

## 影響範囲

この修正は主に以下に影響します。

- フェンス形式コードブロック（````` / `~~~`）
- コードブロックの直前に Markdown 空行がある文書
- コードブロックの本文列位置と装飾列位置

見出し、通常段落、箇条書き、番号付きリスト、引用、表、インライン装飾の基本仕様に変更はありません。

---

## 互換性

- 入力形式の変更: なし
- 設定ダイアログの変更: なし
- 出力ファイル形式（`.xlsx`）の変更: なし
- API/クラス構成の公開仕様変更: なし

既存利用者にとっては、**コードブロックの見た目とセル位置がより仕様通りになる** 修正です。

---

## 備考

README のコードブロック仕様も、今回の動作に合わせて更新しています。

- コード本文は **ブロック開始位置の 1 列右**
- コードブロック装飾は **本文の 1 列左から**
- コードブロック前の Markdown 空行は保持
