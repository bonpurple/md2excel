# md2excel v3.0.1 Release Notes

- リリース日: 2026-09-23
- 前バージョン: v3.0.1

## 概要

v3.0.2 は、v3.0.1 の外部動作を維持したまま、表描画まわりの内部実装を整理したメンテナンスリリースです。

今回の変更では、すでに存在していた表の行役割を通常描画時のスタイル判定にも利用し、罫線スタイルの判定ロジックを一元化しました。

## 主な変更

### 表描画スタイル判定の一元化

- `TableRowStyleRole` から通常表用の `CellStyle` を決定するよう整理
- 行ごとに一度決定したスタイルを、文字入りセルと補完された BLANK セルの両方で使用
- 通常表と引用内表で参照する行役割を共通化し、罫線ルールの二重管理を削減

以下の既存動作は変更していません。

- 表の行役割の決定方法
- BLANK セルの扱い
- 表終了時の罫線確定処理
- 引用装飾処理
- 表文字列解析
- 公開 API

## テスト

既存の238件のテストをすべて実行し、成功を確認しています。

既存テストにより、複数行展開、空セル補完、ヘッダー、引用表、EOF時の最終行処理、保存後の書式など、今回の変更対象となる表描画の主要な挙動を保護しています。

## 互換性

v3.0.2 では、ユーザー向け機能、公開 API、Markdown の解釈、Excel 出力仕様の意図的な変更はありません。

今回の変更は、将来の表罫線・描画ロジック変更時に修正箇所が分散しないようにするための内部リファクタリングです。
