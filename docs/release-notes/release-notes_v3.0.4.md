# md2excel v3.0.4 Release Notes

- リリース日: 2026-10-14
- 前バージョン: v3.0.3

## 概要

v3.0.3から、Markdown→Excel変換処理の内部構造を整理し、回帰テストを補強しました。通常の入力に対するExcel出力を維持することを方針としたリファクタリングです。

## 主な変更

- 入力、描画、保存の各処理に残っていた責務の重複を整理しました。
- インライン解析とリッチテキストのセル書き込み、表の判定と描画、EDT上での処理をそれぞれ分離・共通化しました。
- ブロック境界、引用行の情報、表行のスタイル役割、Setext見出し判定などの配置を整理しました。
- 不要になった内部の委譲メソッドやヘルパーを削除し、内部専用の型・メソッドの可視性を見直しました。
- コード枠や引用スタイルの生成手順を、書式を変えずに読みやすくしました。

## 入力条件に関する変更

XLSXの物理的な列上限を超える表は、表行・セルの作成前に明示的な例外となります。この検査には、アプリケーションで設定した列数や描画範囲ではなく、XLSX形式の物理的な列上限を使用します。

## 互換性について

本プロジェクトは外部向けJavaライブラリとしてのAPI互換性を保証しません。今回の整理では、一部の `public` 宣言を内部向けに変更し、内部参照のなくなった `MarkdownTable.closeTableIfOpen(...)` を削除しました。Javaクラスを直接参照している場合は影響を確認してください。

詳しくは `java-api-policy.md` を参照してください。

## 確認結果

- 変更後の `AllTests` はグリーンです。
- 設定ダイアログは、表示順、参照ボタン、Enter・Escape・キャンセル、入力エラー表示を手動で確認済みです。

## 補足

Excelファイルへの保存では、原子的な移動を試み、対応していない環境では通常の移動へフォールバックします。すべての環境で置換の原子性やディスクへの永続化を保証するものではありません。この保存処理の挙動自体は今回変更していません。
