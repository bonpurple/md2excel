# Release Notes - v2.2.3

## 概要

v2.2.3 は不具合修正のパッチリリースです。  
見出し直後にコードブロックが続く場合、コードブロック開始前に入るべき空行が挿入されず、出力行が 1 行上に詰まる問題を修正しました。

---

## 修正内容

### 1. 見出し直後のコードブロック配置を修正
以下のような Markdown を変換した場合:

````md
## a
```text
b
```
````

従来はコード本文 `b` が **3 行目** に出力されていましたが、  
v2.2.3 では見出し直後に自動空行を挿入し、`b` が **4 行目** に出力されるよう修正しました。

#### 期待される出力
- 2 行目: `a`
- 3 行目: 空行
- 4 行目: `b`

---

## 実装上の変更

- `MdBlockBoundary` の `CODE_FENCE` 境界処理に、  
  **「直前が見出しの場合は自動空行を挿入する」処理** を追加しました。
- これにより、見出し → コードブロックの並びでも、他のブロック要素と同様の見やすいレイアウトになります。

---

## README 更新

- `README.md` の「コードブロック」説明に、  
  **見出し直後にコードブロックが続く場合は開始前に 1 行の自動空行を挿入する** 仕様を追記しました。

---

## 互換性

- 破壊的変更はありません。
- 既存のファイル形式や設定項目に変更はありません。
- 本リリースは **バグ修正のみ** のため、バージョンは `v2.2.2` から `v2.2.3` への patch 更新です。
