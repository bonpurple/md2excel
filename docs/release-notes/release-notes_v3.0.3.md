# md2excel v3.0.3 Release Notes

- リリース日: 2026-09-23
- 前バージョン: v3.0.2

## 概要

v3.0.3 は、v3.0.2 の外部動作を維持しながら、描画処理と設定入力処理の重複を減らし、テストの保守性を改善したメンテナンスリリースです。

## 主な変更

### 描画処理の整理

- 表のセル数調整とセル内テキストの表示行への変換を、行描画処理から分離
- 引用内の箇条書き・番号付きリストの段落初期化を共通化
- 通常・引用内コードブロックの本文書き込みを共通化
- インラインコードとコードブロックで、ASCII系文字とそれ以外にフォントを適用する走査処理を共通化
- 引用装飾の行・列の走査と、セルごとのスタイル適用を分離
- 段落バッファと表の描画結果で、外部から使用しない内部状態を `private` 化

### 設定・保存処理の整理

- 設定フォームの入力検証と設定生成を `Md2ExcelConfigInput` に分離
- フォントキャッシュの検索処理とフォント生成処理を分離
- 保存失敗時に一時ファイルを削除する同一の例外処理を統合

## テスト

- 設定入力の正常系と入力エラーを検証するテストを追加
- 保存後のコードブロックで、日本語の後に続くASCII文字へ適切なフォントが適用されることを確認
- 引用内コードブロックで、引用装飾後も本文セルの上下罫線が維持されることを確認
- フォントキャッシュの再利用時に、新たなフォントが生成されないことを確認
- 描画テストに共通するWorkbook生成と文字セル収集の処理をテスト用ヘルパーへ集約

## 互換性

ユーザー向け機能、公開API、Markdownの解釈、Excelのセル値・配置・書式、保存動作に意図的な変更はありません。
