# Java API の互換性方針

本プロジェクトは Markdown から Excel への変換アプリケーションです。
公開 Java ライブラリとしての利用は想定していません。

## 対象

この方針は、本プロジェクトの Java クラス・メソッドを別のプログラムから
直接参照する場合に適用します。`public` 宣言は、パッケージ間で実装を利用するために
必要な場合もあり、外部向け API であることを意味しません。

## 互換性

Java クラス・メソッドについて、外部利用者に対するソース互換性および
バイナリ互換性は保証しません。内部実装の整理に伴い、公開宣言を持つ型や
メソッドであっても、変更・移動・削除する場合があります。

既知の外部利用がある場合は変更前に影響を確認しますが、それによって
互換性を保証するものではありません。

## この方針に含まれないもの

生成される Excel ファイルの内容や書式など、アプリケーションの利用者に
見える動作は、Java API の互換性とは別に扱います。変更時には要件とテストを
確認します。
